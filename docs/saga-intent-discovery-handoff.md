# redemeine-vpwm.3.3 → .4: durable intent discovery (not executable yet)

The per-instance saga stream is the **only authoritative** source of v1 intent and adjacent timer-fact content. This qualification does not execute effects, fire timers, or certify intent discovery. An ACK confirms the complete turn, not delivery of an intent to an executor.

For .4, build a separate saga-owned indexed projection keyed by `(partitionId, streamId, commitId, eventIndex)` with unique `intentId` and immutable v1 wire content, origin, source identity, physical version and paired timer facts. Index pending work by `(status, nextEligibleAt, intentId)` for bounded pagination; index source position `(partitionId, streamId, commitSequence, eventIndex)` for reconciliation. No partition-wide `queryAll` or global partition scan in the execution path. Duplicate CDC deliveries must compare complete content, not merely IDs. Do not assert a multi-store atomic transaction between the Tapeworm commit and projection.

Tapeworm 0.6's Mongo persistence exposes authoritative partition commits; its existing dispatcher observes Mongo change streams but the current test harness holds the resume state **in memory**. That is not a durable checkpoint or an overlap/backfill proof. .4 must verify actual Mongo 7 CDC behavior against the saga commit collection, persist the resume token only **after** idempotent projection writes, handle resume-token expiry/invalidations and change-stream interruption, and backfill bounded indexed commit ranges overlapping the checkpoint before switching to live consumption. Capture a high-water mark, replay through it, then consume the overlap and prove every authoritative commit up to that mark was indexed; persist coverage watermarks per partition/range and refuse execution if any gap, unsupported event version, incompatible content or unverified range remains. Stream-scoped indexed recovery must account for newly created streams as well as existing streams; prove there is an indexed enumeration mechanism for that range before claiming coverage. A bounded stream lookup alone cannot discover unknown streams.

Recovery tests required for .4: interruption before/after projection write and before/after checkpoint, duplicate/out-of-order CDC, projection rebuild, missing index entry, expired token with concurrent new streams, version refusal, and bounded backfill while appends continue. Until these coverage and recovery tests pass on real Mongo/Tapeworm, **all intents remain non-executable**. If the available index/CDC API cannot establish partition-wide coverage without an unbounded scan, block .4 and file a linked blocker; do not execute only newly observed intents.
